```
┌─────────┐
│  Login  │
└────┬────┘
     │
     ├─→ ┌──────────┐
     │   │ Register │
     │   └────┬─────┘
     │        │
     │        └─→ ┌─────────────┐
     │            │ MainNavigator│
     └───────────→└─────────────┘
```

### Main Flow
```
┌──────────────┐
│  GroupList   │
└──────┬───────┘
       │
       ├─→ ┌──────────────┐
       │   │ CreateGroup  │
       │   └──────┬───────┘
       │          │
       │          └─→ ┌──────────────┐
       │              │ GroupDetail  │
       └──────────────→└──────┬───────┘
                              │
                              ├─→ ┌──────────────┐

                              ├─→ ┌──────────────┐

                              │   └──────────────┘
                              │
                              └─→ ┌──────────────┐
                                  │ ExpenseList  │
                                  └──────────────┘
```

## Component Hierarchy

### Group List Screen
```
GroupListScreen
├── Header
│   └── Text: "Gruplarım"
├── FlatList
│   └── GroupCard
│       ├── Emoji
│       ├── Name
│       └── MemberCount
├── EmptyState (conditional)
│   ├── Message
│   └── CTA Button
└── FloatingActionButton
    └── "+" Icon
```

### Add Expense Screen
```
AddExpenseScreen
├── ScrollView
│   ├── Header: "Harcama Ekle"
│   ├── TitleInput
│   ├── AmountInput
│   ├── CurrencySelector
│   ├── CategorySelector
│   ├── PayerSelector (Radio)
│   ├── ParticipantSelector (Checkbox)
│   └── SubmitButton
```

### Balance Screen
```
BalanceScreen
├── Header: "Bakiyeler"
├── BalanceSection
│   ├── Title: "Kişi Bakiyeleri"
│   └── FlatList
│       └── BalanceCard
│           ├── Name
│           └── Balance (colored)
└── SettlementSection (conditional)
    ├── Title: "Önerilen Transferler"
    └── FlatList
        └── SettlementCard
            ├── From → To
            └── Amount
```

## Notlar

- Tüm wireframe'ler mobile-first tasarım
- Card-based layout kullanılıyor
- Consistent spacing ve padding
- Primary color (#0ea5e9) CTA butonlar için
- Gray scale text hierarchy
- Emoji'ler kategori ve grup gösterimi için
- Floating action buttons önemli aksiyonlar için
- Bottom tab navigation ana navigasyon için
